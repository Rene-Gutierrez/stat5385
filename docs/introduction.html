3 Introduction

3.1 Objectives of Linear Regression

Linear regression is a statistical method used to analyze the relationship between at least two variables: one dependent variable (called response in linear regression) and at least one independent variable (called explanatory variables in linear regression).

Linear regression is typically applied for three main purposes:

  • Description: To describe the relationship between the variables under analysis.
  • Prediction: To forecast the value of the response based on new observations of the explanatory variables.
  • Control: To determine or choose values of the explanatory variable to influence response, when the setting permits a causal interpretation.

3.2 Examples

The following examples illustrate three different goals of linear regression: control, description, and prediction. They also demonstrate that fitting a line is always computationally possible, but that the resulting line is not necessarily an appropriate description of the data.

3.2.1 Ad Spending

Imagine you are a newly hired data scientist at a mattress company. Your manager asks you to analyze the relationship between Google ad spending and mattress sales revenue.

To illustrate this scenario, I have simulated a dataset:

# Ad Spending Example

# Set Seed
set.seed(8272024)

# Data Simulation
x <- rnorm(n    = 100,
           mean = 70,
           sd   = 30)
y <- 1000 + 5 * x + rnorm(n = 100, mean = 0, sd = 100)

# Creates the Data Frame
datAd <- data.frame(cbind(y,x))

# Names the Variables
colnames(datAd) <- c("Revenue", "Ad Spending")

# Saves to csv
write.csv(x    = datAd[, c(1, 2)],
          file = "Ad spending Data.csv", row.names = FALSE)

You can load the dataset as follows:

dat <- read.csv(file = "Ad spending Data.csv")

To visualize the data:

dat <- read.csv(file = "Ad spending Data.csv")
plot(x = dat$Ad.Spending,
     y = dat$Revenue,
     xlab = "Ad Spending ($)",
     ylab = "Revenue ($)")

Next, you can perform a linear regression analysis:

outReg <- lm(Revenue ~ Ad.Spending, data = dat)

The most important results from the regression analysis can be summarized as follows:

summary(outReg)

For now, let’s focus on the estimate for the intercept and the Ad.Spending coefficient. The intercept gives the predicted revenue when ad spending is zero. Based on your analysis, you observe that even without an ad campaign, mattress sales generate 997.3893514. The coefficient for Ad.Spending shows that each dollar spent on ads increases revenue by 5.0247439.

To visualize the regression line:

plot(x = dat$Ad.Spending,
     y = dat$Revenue,
     xlab = "Ad Spending ($)",
     ylab = "Revenue ($)")
abline(a   = outReg$coefficients[1],
       b   = outReg$coefficients[2],
       col = 'red',

The red regression line represents the “best fit” for these variables. In this context, “best fit” means the line that minimizes the sum of the squared vertical differences from each point to the line. For comparison, here are examples of other lines that do not fit as well:

       col = 'red',

       b   = outReg$coefficients[2],
       col = 'blue',

We can expand the range for ad spending and revenue on the plot, as follows:

plot(x = dat$Ad.Spending,
     y = dat$Revenue,
     xlab = "Ad Spending ($)",
     ylab = "Revenue ($)",
     ylim = c(800, 2500),
     xlim = c(0, 200))
abline(a   = outReg$coefficients[1],
       b   = outReg$coefficients[2],
       col = 'red',
       lwd = 2)
abline(h = 0,

Within the range of observed ad spending values 25 to 123, the data provide direct information about the relationship between ad spending and revenue. However, what happens when we consider values outside this range?

While we can predict and control revenue to some extent by adjusting ad spending within the observed range, this confidence may not extend to values beyond it. For instance, it’s plausible that after reaching a certain level of ad spending, the market could become saturated, resulting in diminishing or even no additional revenue despite increased ad spending. Therefore, we should be cautious when extrapolating beyond the observed data, as the relationship may not hold under different conditions.

3.2.2 Wine and Life Expectancy

In the previous example, we were able to manipulate the explanatory variable to influence the outcome. However, there are situations where our primary goal is simply to describe the relationship between two variables, without aiming to control them. In the following example, I generate a dataset that illustrates the relationship between wine consumption and life expectancy in years for an imaginary country. Here’s how the data is simulated:

# Wine and Life Expectancy

# Set Seed
set.seed(8272024)

# Data Simulation
x <- rbinom(n = 20, size = 20, prob = 0.1)
y <- 75 + 1.5 * x + rnorm(n = 20, mean = 0, sd = 3)

# Creates the Data Frame
datWin           <- data.frame(cbind(y,x))

# Names the Variables
colnames(datWin) <- c("Years", "Glasses")

# Saves to csv
write.csv(datWin[, c(1, 2)], file = "Wine Data.csv", row.names = FALSE)

You should be able to generate the exact same data if you copy and paste the code and run it on your computer. Although the data is randomly simulated, I’ve set a seed to ensure that the simulation can be replicated consistently.

We can read and plot the data in as follows:

# Reads the Data
dat <- read.csv(file = "Wine Data.csv")

# Plots the Data
plot(x    = dat$Glasses,
     y    = dat$Years,
     xlab = "Avg. Glasses of Wine per Week",
     ylab = "Life Expectancy (Years)")

Once again, we can perform a linear regression to examine the relationship between the variables and visualize it with a regression line:

# Performs Linear Regression
outReg <- lm(Years ~ Glasses, data = dat)

# Plots
plot(x    = dat$Glasses,
     y    = dat$Years,
     xlab = "Avg. Glasses of Wine per Week",
     ylab = "Life Expectancy (Years)")
abline(a   = outReg$coefficients[1],
       b   = outReg$coefficients[2],
       col = 'red',
       lwd = 2)

Given the regression line, can we confidently conclude that increasing wine consumption leads to a longer life expectancy?

The simulation is designed to generate a positive association between the variables. The fact that we used \(x\) to generate \(y\) computationally should not be interpreted as evidence that an analogous observed association in real data would be causal.

3.2.3 Burger Demand

Imagine you work at a burger franchise where prices change daily. As the franchise manager, you want to predict the demand for burgers at a given price. Over the past 100 days, you’ve collected data on the number of burgers sold at each price set by the franchise’s main office. Here’s what your data looks like:

# Reads the Data
dat <- read.csv(file = "Burger Data.csv")

# Plots the Data
plot(x    = dat$Price,
     y    = dat$Burgers,
     xlab = "Price ($)",
     ylab = "Burgers Sold")

Is this dataset a good candidate for linear regression? While it’s true that we can always fit a line to any dataset, the real question is whether that line meaningfully represents the relationship between the variables. Here’s what happens when we apply linear regression to this data:

# Performs Linear Regression
outReg <- lm(Burgers ~ Price, data = dat)

# Plots
plot(x    = dat$Price,
     y    = dat$Burgers,
     xlab = "Price ($)",
     ylab = "Burgers Sold")
abline(a   = outReg$coefficients[1],
       b   = outReg$coefficients[2],
       col = 'red',
       lwd = 2)

Do you think this is a good fit for the data? The regression line appears to be inadequate for both low and high price points. Since the number of burgers sold cannot be negative, the linear model becomes unreasonable over ranges of prices for which it predicts zero or negative demand.

3.3 Intro to SLR

Simple linear regression (SLR) is a linear regression model with a single explanatory variable. It focuses on the linear relationship between one explanatory variable and one response, making it the most basic form of linear regression analysis.

3.3.1 A Path Not Taken

The basic idea behind linear regression is to find the “best line” that describes the data. This idea admits several interpretations. One interpretation is to measure the distance between a candidate line and the data points. For a line \(\mathcal{l}\) given by

\[ ax + by + c = 0 \]

the distance from a point \((x_i,y_i)\) to that line is

\[ d_i = d(\mathcal{l},(x_i,y_i)) = \frac{|ax_i + by_i + c|}{\sqrt{a^2+b^2}}. \]

We could then pose the optimization problem

\[ \min_{a,b,c: a^2 + b^2 > 0} \sum_{i=1}^n d_i. \]

However, those familiar with regression will recognize that this is not the standard linear regression formulation. That does not make the distance-minimization problem unreasonable, only that its solution will generally differ from the usual linear regression solution.

The standard least-squares formulation of linear regression makes a particular optimization choice because of its convenient properties.. In the next section we introduce a model that refines the notion of a “best line.”

3.3.2 SLR Model

The model for simple linear regression is as follows:

\[y_i = \beta_0 + \beta_1 x_i + e_i, \quad i\in\{1,\ldots,n\}\]

where:

  • \(y_i\) represents the \(i\)-th observation of the response.
  • \(x_i\) represents the \(i\)-th observation of the explanatory variable.
  • \(e_i\) represents the \(i\)-th observation of the error term.
  • \(\beta_0\) is the intercept of the linear model, or regression line.
  • \(\beta_1\) is the slope of the linear model, or regression line.
  • \(n\) is the number of observations for both variables.

Notice that in this framework, the error measures the signed vertical difference between the observed point and the regression line, rather than the perpendicular distance from the point to the line. Also, note that we are not making any assumptions about the error terms.

In the case of the wine example, we generated the data based on the following linear model:

\[y_i = 75 + 1.5 x_i + e_i \]

dat <- read.csv(file = "Wine Data.csv")
plot(x    = dat$Glasses,
     y    = dat$Years,
     xlab = "Avg. Glasses of Wine per Week",
     ylab = "Life Expectancy (Years)")
abline(a   = 75,
       b   = 1.5,
       col = 'red',
       lwd = 2)
abline(v   = 0,
       lwd = 2)
text(x = 0.25, y = 76, expression(beta[0] ~ "=75"))
text(x = 3.25, y = 79, expression(beta[1] ~ "=1.5"))
segments(x0 = c(2, 3),
         x1 = c(3, 3),
         y0 = c(78, 78),
         y1 = c(78, 79.5),
         lwd = 2,
         col = 'blue')

In this case, the intercept \(\beta_0\) is meaningful, as it represents the value predicted by the linear component of the model for a person who drinks no wine.. However, depending on the data, the intercept may or may not have a meaningful interpretation. The slope \(\beta_1\) indicates that for each additional glass of wine consumed per week, our model predicts an increase of 1.5 years in life expectancy.

In practice, we rarely know the true regression line. Instead, it must be estimated from the data. The goal is to find the “best” line that fits the data, where “best” means the line that minimizes the sum of squared errors (SSE) between the observed values and the values predicted by the model.

3.3.3 Possible Optimization Problems

Other than minimizing the sum of squared errors (SSE), we can consider the following alternative optimization problems. Here \((e_i(\beta_0,\beta_1)=y_i-(\beta_0+\beta_1 x_i)\) denotes the vertical error associated with a candidate line.

3.3.3.1 Minimizing the Sum of Absolute Errors

\[ \min_{\beta_0, \beta_1} \sum_{i=1}^n |e_i(\beta_0, \beta_1)| \]

This L1 criterion is common in the machine-learning community and is more robust to outliers than the SSE. Laplace was among the first to investigate this approach when developing early methods for fitting lines to data.

3.3.3.2 Minimizing the Maximum Error

\[ \min_{\beta_0, \beta_1} \max_{i=1}^n |e_i(\beta_0, \beta_1)| \]

The minimax approach focuses on reducing the largest error and is appropriate when large errors can be catastrophic. Laplace also explored this formulation in his early work.

3.3.3.3 Minimizing the Sum of Squared Errors

\[ \min_{\beta_0, \beta_1} \sum_{i=1}^n e_i(\beta_0, \beta_1)^2 \]

This is the standard formulation in simple linear regression (the least squares criterion), introduced by Legendre and Gauss (apparently independently).It remains widely used because of its convenient mathematical and computational properties, which we will analyze in the following sections.

3.4 Exercises

The following exercises explore how different characteristics of a dataset affect the usefulness of a linear regression model. The main objective is not simply to fit a regression line, since a line can always be fitted, but to determine whether that line provides a meaningful representation of the relationship between the variables.

For each exercise involving simulated or collected data, begin by plotting the data before fitting a regression model.

3.4.1 Exercise 1: Changing the Intercept

Simulate \(100\) observations from the relationship

\[ y = \beta_0 + 5x + e, \]

where \(x\) is generated using

x <- runif(n = 100, min = 0, max = 100)

and \(e\) is generated using rnorm() with mean \(0\) and standard deviation \(50\).

Consider the following three values for the intercept:

\[ \beta_0 = 0, \qquad \beta_0 = 500, \qquad \beta_0 = 1000. \]

For each value:

  1. Simulate the response variable \(y\) using the same values of \(x\) and \(e\).
  2. Plot \(y\) against \(x\).
  3. Fit a linear regression using lm().
  4. Add the fitted regression line to the plot.
  5. Compare the three plots.
  6. Explain what changes when the intercept changes and what remains approximately the same.
  7. Give a practical interpretation of the intercept in each simulation.

3.4.2 Exercise 2: Changing the Slope

Generate one set of \(100\) values of \(x\) between \(0\) and \(100\) and one set of random errors. Using the same \(x\) and errors, simulate

\[ y = 500 + \beta_1x + e \]

for

\[ \beta_1 = -5, \qquad \beta_1 = 0, \qquad \beta_1 = 2, \qquad \beta_1 = 10. \]

For each dataset:

  1. Make a scatterplot.
  2. Fit a linear regression.
  3. Add the fitted line.
  4. Record the estimated slope and intercept.
  5. Describe the direction of the relationship.
  6. Explain how the magnitude of the slope changes the relationship between \(x\) and \(y\).
  7. Explain what a slope close to zero means.

3.4.3 Exercise 3: Different Intercepts and Slopes

Consider the following four relationships:

\[ y = 100 + 2x + e, \]

\[ y = 100 + 8x + e, \]

\[ y = 700 + 2x + e, \]

and

\[ y = 700 - 4x + e. \]

Use the same \(100\) values of \(x\) and the same random errors for all four datasets.

  1. Simulate all four datasets.

  2. Create a scatterplot for each.

  3. Before fitting the regression models, identify which datasets have:

    • the same intercept,
    • the same slope,
    • positive relationships,
    • negative relationships.

  4. Fit a regression to each dataset.

  5. Compare the estimated coefficients with the values used to generate the data.

  6. Explain how the plot allows you to distinguish changes in slope from changes in intercept.

3.4.4 Exercise 4: Increasing the Amount of Noise

Generate \(100\) observations from

\[ y = 1000 + 5x + e, \]

where \(x\) is between \(0\) and \(100\).

Generate four datasets by changing only the standard deviation of \(e\):

\[ 10,\qquad 50,\qquad 200,\qquad 500. \]

For each dataset:

  1. Plot the data.
  2. Fit and display the regression line.
  3. Compare the estimated slopes.
  4. Describe how the appearance of the relationship changes as the variability increases.
  5. At what point does the linear relationship become difficult to recognize visually?
  6. Does increased variability necessarily change the underlying slope used to generate the data?

3.4.5 Exercise 5: No Relationship

Generate \(100\) observations of \(x\) using runif() and separately generate \(100\) observations of \(y\) using rnorm(), so that the construction does not impose a relationship between them.

For example, \(x\) might represent advertising expenditure while \(y\) represents sales from a process that is completely unrelated to advertising.

  1. Plot the data.
